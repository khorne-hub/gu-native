Build the game code on the phone (Settings, Build the game code): the tools it downloads

The first time it runs, the builder downloads these tools from their official sources, checks each one against its
SHA-256 and keeps them in the app's private files. They are not in the APK, and none of them is game data. The builder
runs them with two small programs of the app (libpyrun.so, libzigcc.so).
